# 混沌测绘志 / CHAOS ATLAS

一部关于奇异吸引子、初始敏感性与李雅普诺夫指数的实时互动图谱。所有轨道、吸引子图像与谱估计都在浏览器内计算，没有视频、远程资源或预渲染图像。

## 运行

直接用浏览器打开 [`index.html`](./index.html) 即可，无需构建、安装依赖或启动服务器。页面完全离线可用。

建议使用较新的 Chrome、Edge、Safari 或 Firefox。

## 互动

- **观测台**：拖动相空间旋转视角，滚轮缩放，双击归位；切换 6 个动力系统，调整参数，观察吸引子变形与李雅普诺夫谱重新估算。
- **双轨道敏感性实验**：改变初始差异 δ₀，观察两条几乎相同的轨道如何以指数速度分离，并读取预测半径。
- **分岔图**：指针在图上移动即可扫描参数 r；滑块和周期预设也会实时更新轨道、周期和映射的 λ。
- **轨道档案**：点击任意卡片，将对应系统载入观测台。
- 顶部进入 `INDEX`（移动端）可跳转章节；支持 `Esc` 关闭。

## 方法

- 轨道积分：四阶龙格–库塔（RK4）。
- 李雅普诺夫谱：状态方程与变分方程同步积分，周期性地对切空间基做 Gram–Schmidt 正交化，累加对数拉伸率（Benettin 方法）。
- 逻辑斯蒂映射：`xₙ₊₁ = r xₙ(1 − xₙ)`；分岔图用 1000 步暂态和 210 次迭代绘制。
- 页面中的指数是**有限时间估计**，会随时间与参数变化继续波动。

在经典参数 α = 1.89 下，Halvorsen 系统收敛到一条稳定的周期轨道；页面将其作为“吸引子不必混沌”的对照，并标出 `PERIODIC`。其余默认系统处于混沌区。
